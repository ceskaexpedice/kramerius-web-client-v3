# Kramerius Web Client v3 Wiki

Dokumentace ke konfiguraci a správě webového klienta systému Kramerius.

## Co zde najdete
Tato wiki popisuje konfigurační soubory aplikace, jejich význam a způsob použití.

- [Hlavní konfigurační soubor](https://github.com/ceskaexpedice/kramerius-web-client-v3/wiki/Hlavn%C3%AD-konfigura%C4%8Dn%C3%AD-soubor)
  - základní nastavení aplikace, název, branding, chování
- [Konfigurace úvodní strany](https://github.com/ceskaexpedice/kramerius-web-client-v3/wiki/Konfigurace-%C3%BAvodn%C3%AD-strany)
  - obsah homepage, pořadí sekcí, doporučené tagy, kurátorované bloky
- [Konfigurace licencí](https://github.com/ceskaexpedice/kramerius-web-client-v3/wiki/Konfigurace-licenc%C3%AD)
  - mapování a zobrazení licencí v aplikaci
- [Návod](https://github.com/ceskaexpedice/kramerius-web-client-v3/wiki/N%C3%A1vod)
  - návod popisuje, jak spustit klienta - webové rozhraní pro Kramerius

## Struktura konfigurace
Konfigurační soubory se nacházejí v `public/local-config/`.
